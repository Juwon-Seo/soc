# 데미안 더프(Damien Duff, 프리셋 `duff`, 접두어 DUF) 판정 기록

재현: `python3 players/duff/build_duff.py` (raw/ → duff.json·src/data/duf.js). `--debug`(Elo 출처·도움 판정), `--cross`(동료 대조), `--fm`(FotMob 골 대조).
보조: `elo_tables.py`(순위별 값·직접 추정), `note_duff.py`(설명 문장). 월콧 build를 바탕으로 함.

- **뺀 경기 1**: 2015-10-02 보헤미안전(TM IRLC = 렌스터 시니어컵 준결승, 73분, 골·도움 없음). 지역(주) 컵이고 영어 위키백과(섐록 9경기)·FotMob(9경기) 모두 세지 않음 → 628경기. 사용자 확인 대상(경계 사례, 수치 영향 0).
- 위키백과 차이: 블랙번 223경기(1999-00 리그 39 vs TM 37, 2000-01 리그컵 2 vs TM 1). 경기 단위 근거 없음 → TM. 멜버른 시티 위키 16경기(FFA컵 1) vs TM·FotMob 15 → 단일 출처라 넣지 않음.
- 프로 리그 규칙(v1.159/v1.163): 프리미어리그, 잉글랜드 2부(블랙번 1999-2001 퍼스트 디비전, 뉴캐슬 2009-10 챔피언십 1경기), A리그(프로 1부), 아일랜드 1부 2015(위키백과 'professional association football league', 전 구단 풀타임 프로는 2025부터 → 경계지만 통산 기록에 포함되므로 셈). 제외 시즌 없음.
- 은퇴: 마지막 경기 2015-10-30 드로이다전, TM 은퇴 2015-12-21 → retired true.
