# Club colours research (club SOC calculator)

Input: /tmp/claude-0/-home-user-soc/f573789f-135b-51ba-9a2c-3a06b5e8def1/scratchpad/colors/clubs_<N>.csv (name_ko = Korean club name shown in the calculator, keys = internal club keys, context = calculator player ids who played there, to identify the club; e.g. "ronaldinho" = Ronaldinho, "rivaldo" = Rivaldo, "kaka" = Kaká).
Output: /tmp/claude-0/-home-user-soc/f573789f-135b-51ba-9a2c-3a06b5e8def1/scratchpad/colors/colors_<N>.csv with columns:
name_ko, keys, club_en, c1, c2, c3, source_url, note
- One row per input row. If the keys of one Korean name are really two different clubs (check the context), write one row per club and split the keys.
- c1 = the club's main colour (the dominant colour of the traditional home shirt / the first colour in the club's official colours), c2 = second club colour, c3 = third colour if the club officially has one (else empty). Use 6-digit hex like #A50044. White (#FFFFFF) and black (#000000) are allowed when they really are club colours (e.g. Real Madrid c1 #FFFFFF, Juventus c1 #000000 c2 #FFFFFF) — the calculator handles contrast itself. Give the club's real brand shades where a source states them (official brand guides, Wikipedia "colours"/kit templates' body1/shorts1 hex values, team colour sites); otherwise use the Wikipedia infobox kit colours (the `|body1=`, `|shorts1=`, `|socks1=` hex values of the home kit in the club article's wikitext, `https://en.wikipedia.org/w/index.php?title=<Club>&action=raw`).
- source_url: the page you took the colours from. note: anything special (historical colours differ, club renamed, etc.). Use the club's traditional colours (not a one-off third kit).
Rules: Wikipedia api.php is rate-limited from this IP — use index.php?title=...&action=raw with ~1.5 s between requests. Never use zerozero, ogol, worldfootball, 11v11, fbref or sofascore; never bypass bot checks. Do not edit anything under /home/user/soc; do not commit. Report counts, rows you were unsure about, and any Korean name that maps to two clubs.
